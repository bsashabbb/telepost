/

Получить список всех постов, созданных с текущего IP-адреса. Доступно через GET и POST.

GET-запрос:

curl http://localhost:5000/

POST-запрос:

curl -X POST http://localhost:5000/

Пример ответа (для обоих методов):

{
    "ok": true,
    "result": [
        {"id": 1, "title": "Заголовок 1", "author": "127.0.0.1"},
        {"id": 2, "title": "Заголовок 2", "author": "127.0.0.1"}
    ]
}
GET
POST
/new

Создать новый пост. Доступно через GET (форма) и POST (отправка данных).

GET-запрос:

Получить HTML-форму для создания поста.

curl http://localhost:5000/new

POST-запрос:

Параметры:

  • title (строка, минимум 5 символов)
  • content (строка, минимум 10 символов)
curl -X POST -F "title=Новый пост" -F "content=Текст поста" http://localhost:5000/new

Пример ответа:

{
    "ok": true,
    "result": {
        "id": 3,
        "title": "Новый пост",
        "content": "Текст поста",
        "author": "127.0.0.1"
    }
}

/post/<id>

Получить пост по его ID. Доступно через GET (HTML) и POST (JSON).

GET-запрос:

Получить пост в формате HTML.

curl http://localhost:5000/post/1

Пример ответа:

<h1>Заголовок поста</h1>
<div class="post-content">Содержание поста</div>

POST-запрос:

Получить пост в формате JSON.

curl -X POST http://localhost:5000/post/1

Пример ответа:

{
    "ok": true,
    "result": {
        "id": 1,
        "title": "Заголовок поста",
        "content": "Содержание поста",
        "author": "127.0.0.1"
    }
}

/raw/<id>

Получить сырой Markdown-контент поста. Доступно через GET (HTML) и POST (JSON).

GET-запрос:

Получить сырой Markdown в формате HTML.

curl http://localhost:5000/raw/1

Пример ответа:

<pre># Заголовок поста
Текст поста</pre>

POST-запрос:

Получить сырой Markdown в формате JSON.

curl -X POST http://localhost:5000/raw/1

Пример ответа:

{
    "ok": true,
    "result": "# Заголовок поста\nТекст поста"
}

/edit/<id>

Редактировать пост. Доступно через GET (форма) и POST (отправка данных).

GET-запрос:

Получить HTML-форму для редактирования поста.

curl http://localhost:5000/edit/1

POST-запрос:

Параметры:

  • title (строка, минимум 5 символов)
  • content (строка, минимум 10 символов)
curl -X POST -F "title=Обновлённый заголовок" -F "content=Обновлённый текст" http://localhost:5000/edit/1

Пример ответа:

{
    "ok": true,
    "result": {
        "id": 1,
        "title": "Обновлённый заголовок",
        "content": "Обновлённый текст",
        "author": "127.0.0.1"
    }
}
POST
/delete/<id>

Удалить пост (требуется IP автора).

curl -X POST http://localhost:5000/delete/1

Пример ответа:

{
    "ok": true,
    "result": "Post deleted"
}

📤 Форматы ответов

Успех (200 OK):

{
    "ok": true,
    "result": { ... }
}

Ошибка (400 Bad Request):

{
    "ok": false,
    "error_code": 400,
    "description": "Title must be at least 5 characters long"
}

Ошибка (403 Forbidden):

{
    "ok": false,
    "error_code": 403,
    "description": "You are not authorized to edit this post"
}

Ошибка (404 Not Found):

{
    "ok": false,
    "error_code": 404,
    "description": "Post Not Found"
}
